# Plugin Store promo images

Marketing images for the Twinsies listing on the Craft Plugin Store, rendered in the same theme as
the plugin's marketing page at
[justinholt.com/plugins/craft-twinsies](https://justinholt.com/plugins/craft-twinsies).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `twinsies-promo-N.png`, 1920×1080 (rendered at 2× in headless Chrome,
then downsampled so the type stays crisp).

## Slides

| # | Slide | Shows |
|---|-------|-------|
| 1 | Cover — name, tagline, app icon, price | — |
| 2 | One order, two shapes | sales invoice vs journal transaction, side by side |
| 3 | Your chart of accounts, in a dropdown | the mapping fallback chain |
| 4 | VAT that survives the return | 21 / 9 / 0 → VH / VL / VN |
| 5 | It refuses rather than guess | the reconciliation, and the refusal |
| 6 | Twinfield knows first | an open-items table settling to paid |
| 7 | The reason, not just the refusal | console output, including a real rejection |

Slide 2 is the one that has to land: the mode switch is the thing no generic connector offers, and
the reason a shop without Twinfield's invoicing module can use this at all.

Every slide is pure CSS and type — there are no control-panel screenshots yet. When the CP settles,
screenshot slides can be added alongside these without redoing anything: copy the `.shot` /
`.viewport` pattern from `craft-appleseed-website/promos/slides.html`.

## Editing

Everything lives in `slides.html` — one `<section class="slide">` per image. The palette and fonts
are the plugin site's: accent `#1b5fa8`, amber `#f0a22e`, Jersey 20 for display, Inter for body.

`assets/` holds the fonts and two icon files:

- `icon.svg` — the app icon, used for the cover mark and the footer lockup. Copy it from
  `../src/icon.svg` whenever the icon changes.
- `watermark.svg` — the two sheets as **outlines**, not the filled app icon. The icon's rectangles
  are solid, and at watermark scale two solid slabs read as a hard-edged grey box across every
  slide. Outlining them keeps the "same thing, twice" idea legible at 6% opacity.

`fonts.css` is generated by `build.sh` (the woff2 files are base64-inlined so Chrome's `file://`
origin rules can't block them) and is not checked in.

## Numbers on the slides

The figures are illustrative but internally consistent — `119.79` on slide 2 is `99.00` net plus
21% VAT, and the sheet on slide 6 uses Dutch decimal separators because that is what a Twinfield
user sees. Keep them that way; a promo that does not add up is the wrong advert for this plugin.
